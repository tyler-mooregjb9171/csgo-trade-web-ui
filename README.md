## Getting Started

First, clone the repository and install its dependencies using the Node.js package manager of your choice.

git clone https://github.com/tyler-mooregjb9171/csgo-trade-web-ui.git
cd csgo-trade-front
npm install

Once installation is complete, run the development server to load the application locally.

npm start

## Development Commands

A typical development session involves starting the local server, modifying Angular source code, and allowing the application to reload as changes are made.

The primary commands are:

npm start
npm run build
npm test
npm run e2e

Run `npm run build` to create distributable application files. The test commands can be used to check updates before they are merged or published.
